- `dune build @doc` now drives odoc with the v3 model: units are
  compiled with `--parent-id`, linked with `-P`/`-L` package and
  library trees, and documentation for dependencies installed in the
  opam switch (managed by odd) is referenced in place. Sub-libraries'
  HTML now nests under their package directory. Requires an odoc with
  the `-o` output override for `odoc compile`. (#99999, @jonludlam)
